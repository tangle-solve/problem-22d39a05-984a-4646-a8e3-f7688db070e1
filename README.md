### ALGO-000104: Projection Games Conjecture
- **Subfield:** Approximation algorithms and constraint satisfaction
- **Open:** Obtain near-linear-size reductions to projection games with inverse-polynomial soundness and alphabet size polynomial in the inverse soundness.
- **Status:** Open in the full parameter regime. Bafna–Minzer–Vyas’s 2025 HDX-based PCP work achieves strong small-constant-soundness results, not automatically the full inverse-polynomial target.
- **Type:** theory
- **Why:** Would sharpen hardness for set cover and numerous label-cover-based reductions.
- **Key works:** Moshkovitz (2015), *The Projection Games Conjecture and the NP-Hardness of ln n-Approximating Set-Cover*; Bafna, Minzer, and Vyas, arXiv:2407.12762, DOI: 10.1145/3717823.3718197.
- **Related:** High-dimensional expansion—efficient agreement testing.
